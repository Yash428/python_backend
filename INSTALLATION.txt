================================================================================
JITSI TRANSCRIPTION PIPELINE - INSTALLATION & DEPLOYMENT GUIDE
================================================================================

🎯 OBJECTIVE:
Convert Jitsi Meeting MP4 recordings to text transcripts with timestamps,
using offline OpenAI Whisper. Production-ready, fully implemented.

================================================================================
SYSTEM REQUIREMENTS
================================================================================

MINIMUM:
- OS: Windows 10/11 (Linux/macOS also supported)
- Python: 3.10 or higher
- RAM: 8GB minimum (16GB+ recommended)
- Disk: 20GB free space (for models and outputs)
- CPU: Any modern processor (GPU optional)

REQUIRED SOFTWARE:
- Python 3.10+ (https://python.org/downloads)
- FFmpeg (https://ffmpeg.org/download.html)

================================================================================
INSTALLATION STEPS
================================================================================

STEP 1: Install Python 3.10+
────────────────────────────────────────────────────────────────────────────
1. Download from: https://www.python.org/downloads/
2. Run installer
3. IMPORTANT: Check "Add Python to PATH" during installation
4. Complete installation

Verify:
  Open CMD/PowerShell and run:
  python --version
  
  Should output: Python 3.10.x or higher


STEP 2: Install FFmpeg
────────────────────────────────────────────────────────────────────────────
Windows Users:
  1. Download: https://ffmpeg.org/download.html
  2. Choose: Windows builds → Full build
  3. Extract to: C:\ffmpeg (or your preferred location)
  4. Add to PATH:
     a. Press Win + X → System
     b. Click "Advanced system settings"
     c. Click "Environment Variables"
     d. Find "Path" under System variables → Edit
     e. Click "New" and add: C:\ffmpeg\bin
     f. Click OK and close dialogs
     g. RESTART your terminal/command prompt

Verify:
  Open NEW cmd/PowerShell and run:
  ffmpeg -version
  ffprobe -version
  
  Both should show version information


Linux (Ubuntu/Debian):
  sudo apt-get update
  sudo apt-get install ffmpeg
  
  Verify:
  ffmpeg -version
  ffprobe -version


macOS:
  brew install ffmpeg
  
  Verify:
  ffmpeg -version
  ffprobe -version


STEP 3: Download/Extract Project
────────────────────────────────────────────────────────────────────────────
Option A: Git Clone
  git clone <repository-url>
  cd jitsi

Option B: Download ZIP
  1. Download project ZIP file
  2. Extract to desired location
  3. Open command prompt in project folder


STEP 4: Create Virtual Environment
────────────────────────────────────────────────────────────────────────────
Windows:
  python -m venv venv
  venv\Scripts\activate
  
  Your prompt should show: (venv)

Linux/macOS:
  python3 -m venv venv
  source venv/bin/activate
  
  Your prompt should show: (venv)


STEP 5: Install Python Dependencies
────────────────────────────────────────────────────────────────────────────
With virtual environment activated:
  pip install --upgrade pip
  pip install -r requirements.txt

This will install:
  - openai-whisper (speech recognition)
  - torch & torchaudio (ML framework)
  - numpy, scipy (scientific computing)
  - pydub (audio processing)

NOTE: First run takes 5-10 minutes to download Whisper model (~141MB)


STEP 6: Verify Installation
────────────────────────────────────────────────────────────────────────────
Run validation script:
  python test_installation.py

This checks:
  ✓ Python version
  ✓ FFmpeg installation
  ✓ All dependencies
  ✓ Project structure
  ✓ Core functions

Expected output: "✓ ALL CHECKS PASSED!"

FIRST TRANSCRIPTION
================================================================================

Method 1: Using Python CLI (Recommended)
────────────────────────────────────────────────────────────────────────────
1. Place MP4 file in: recordings/meeting.mp4

2. Ensure virtual environment is activated:
   Windows: venv\Scripts\activate
   Linux/Mac: source venv/bin/activate

3. Run transcription:
   python run_pipeline.py recordings/meeting.mp4

4. Wait for completion (processing time varies by file length)

5. Check outputs in: transcripts/


Method 2: Windows Batch Script (Easy)
────────────────────────────────────────────────────────────────────────────
1. Place MP4 in: recordings/meeting.mp4
2. Double-click: transcribe.bat
3. Enter filename when prompted
4. Wait for completion


Method 3: Batch Processing (Multiple Files)
────────────────────────────────────────────────────────────────────────────
1. Place all MP4 files in: recordings/

2. Run batch processor:
   python batch_transcribe.py recordings/

3. Or double-click: batch.bat

4. Wait for all files to process


USAGE OPTIONS
────────────────────────────────────────────────────────────────────────────
Basic (uses defaults):
  python run_pipeline.py meeting.mp4

With specific model:
  python run_pipeline.py meeting.mp4 --model small

With language:
  python run_pipeline.py meeting.mp4 --language en

Clean up temp files:
  python run_pipeline.py meeting.mp4 --cleanup

Combined:
  python run_pipeline.py meeting.mp4 --model base --language en --cleanup

Model choices:
  - tiny: Fast (39MB)
  - base: Recommended (141MB) ⭐
  - small: High quality (244MB)
  - medium: Very high quality (769MB)
  - large: Best quality (2.9GB)

Language codes:
  en, es, fr, de, it, pt, nl, ru, zh, ja, ko, and 70+ more

================================================================================
OUTPUT FILES
================================================================================

After transcription, check: transcripts/ folder

Files generated (for input: meeting.mp4):

meeting.txt
  - Plain text transcript
  - No timestamps
  - Use for: reading, searching, archiving

meeting.json
  - Structured data with timestamps
  - Segment-level information
  - Use for: database import, app integration

meeting.srt
  - SRT subtitle format
  - For video players
  - Use for: embedding in videos, editing software

meeting_timestamps.txt
  - Human-readable timeline
  - Multiple views (detailed, compact, speaker)
  - Use for: navigation, printing, sharing

meeting_markers.edl
  - EDL format for video editing
  - Segment boundaries marked
  - Use for: Premiere, Final Cut, DaVinci Resolve

PERFORMANCE EXPECTATIONS
================================================================================

Processing Speed (base model, Windows CPU):

5 min video    → 2-3 min processing    ⚡ Fast
30 min video   → 10-15 min processing  ⏱️ Standard
1 hour video   → 25-35 min processing  ⏳ Normal
2 hour video   → 50-70 min processing  📼 Full session

Memory Usage by Model:

tiny   → 2-3 GB RAM
base   → 4-5 GB RAM      ⭐ Recommended
small  → 6-7 GB RAM
medium → 10-12 GB RAM
large  → 14+ GB RAM

For slower hardware: Use "tiny" or "small" model
For better quality: Use "small" or "medium" model
For best quality: Use "large" model (requires high-end hardware)

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: "FFmpeg not found"
SOLUTION:
  - Verify FFmpeg installed: ffmpeg -version
  - Check it's in PATH:
    Windows: where ffmpeg
    Linux/Mac: which ffmpeg
  - If not in PATH, add it (see STEP 2 above)
  - RESTART your terminal after adding to PATH


PROBLEM: "No module named 'whisper'"
SOLUTION:
  - Activate virtual environment:
    venv\Scripts\activate (Windows)
    source venv/bin/activate (Linux/Mac)
  - Reinstall dependencies:
    pip install --upgrade openai-whisper torch


PROBLEM: "Slow transcription / High RAM usage"
SOLUTION:
  - Use smaller model:
    python run_pipeline.py meeting.mp4 --model tiny
  - Or:
    python run_pipeline.py meeting.mp4 --model small
  - Check available RAM in Task Manager
  - Close other applications


PROBLEM: "Python 3.10+ not found"
SOLUTION:
  - Download: https://python.org/downloads
  - Install latest Python 3.12 LTS
  - Make sure to check "Add to PATH"
  - Restart terminal


PROBLEM: "Permission denied" on Linux/Mac
SOLUTION:
  - Make scripts executable:
    chmod +x run_pipeline.py
    chmod +x batch_transcribe.py
  - Or run with python:
    python run_pipeline.py meeting.mp4


PROBLEM: "UnicodeDecodeError" with non-English audio
SOLUTION:
  - Specify language explicitly:
    python run_pipeline.py meeting.mp4 --language es (Spanish)
    python run_pipeline.py meeting.mp4 --language fr (French)


PROBLEM: File processing never completes
SOLUTION:
  - Check file size (must be accessible MP4)
  - Try with smaller --model
  - Monitor CPU usage (should be 60-100%)
  - Check available disk space
  - Try smaller test file first


PROBLEM: Output files not created
SOLUTION:
  - Check transcripts/ folder exists:
    Windows: mkdir transcripts
    Linux/Mac: mkdir -p transcripts
  - Run test_installation.py to verify setup
  - Check logs for error messages


PROBLEM: "CUDA out of memory" (GPU users)
SOLUTION:
  - This project uses CPU by default
  - If using GPU: Not recommended for this setup
  - Stick with CPU mode (default)


FOR MORE HELP:
  1. Check README.md - Detailed troubleshooting section
  2. Run test_installation.py - Verify installation
  3. Review logs for specific error messages
  4. Check FFmpeg is properly installed

INTEGRATION WITH YOUR APPLICATION
================================================================================

Loading Output JSON in Python:

  import json
  
  with open("transcripts/meeting.json") as f:
      data = json.load(f)
  
  for segment in data["segments"]:
      print(f"{segment['start']:.2f}s: {segment['text']}")

Loading Output in JavaScript:

  fetch('transcripts/meeting.json')
    .then(r => r.json())
    .then(data => {
      data.segments.forEach(seg => {
        console.log(`${seg.start.toFixed(2)}s: ${seg.text}`);
      });
    });

Using in Web Application:

  1. Generate transcription:
     python run_pipeline.py meeting.mp4
  
  2. Copy meeting.json to your web app static folder
  
  3. Load and display:
     const response = await fetch('/transcripts/meeting.json');
     const transcript = await response.json();
     
     // Build searchable, timestamped UI
     transcript.segments.forEach(seg => {
       // Display segment with clickable timestamp
     });
