💾 OUTPUT FILES GENERATED

For input: meeting.mp4

Output Location: transcripts/

Files Created:
  1. meeting.txt
     → Plain text transcript
     → Size: ~50-200 KB (varies by content)
     → Use for: reading, searching, archiving

  2. meeting.json
     → JSON with segment timestamps
     → Size: ~100-300 KB
     → Use for: app integration, databases, API responses

  3. meeting.srt
     → SRT subtitle format
     → Size: ~50-200 KB
     → Use for: video players, editing software

  4. meeting_timestamps.txt
     → Human-readable timeline
     → Multiple views included
     → Size: ~100-300 KB
     → Use for: navigation, printing, sharing

  5. meeting_markers.edl
     → EDL video editing markers
     → Size: ~20-50 KB
     → Use for: Premiere, Final Cut, DaVinci Resolve
